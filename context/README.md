## Regras

1. Atualizar o `.md` quando mudar papel, stack ou resultado relevante — **antes** ou junto do diff em `src/data/*` / `resume/*`.
2. **Não** colar secrets, tokens, URLs internas de cliente, dados de card DOP, nem código proprietário.
3. Trabalho (Olie / Enterscience): só o que pode ir a público (stack genérica, tipo de produto, contribuição). Detalhe interno fica fora.
4. Ao inventar bullet de currículo/site: preferir este pack + `src/data/*`; se faltar fato, perguntar — não especular.

## Formato de cada pack

- Tipo / desde quando / links públicos  
- O que é (1–3 frases)  
- Meu papel  
- Stack (público)  
- Bullets úteis para currículo/portfólio  
- O que **não** publicar
