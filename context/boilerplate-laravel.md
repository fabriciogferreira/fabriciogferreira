# boilerplate-laravel

- **Tipo:** comunidade / template
- **Meta-repo:** `~/git/boilerplate-laravel/` (clone app Laravel + sandbox Pest/mutation)
- **Host-card:** `workvm-host-card open --project boilerplate-laravel`

## O que é

Boilerplate Laravel reutilizável (compose.dev, prompts de implementation/correction/pre-deploy, sandbox com mutation/coverage). Base para apps Laravel novos no fluxo WorkVM.

## Meu papel

Autor / maintainer do template e da amarração WorkVM.

## Stack (público)

Laravel, PHP, Docker, Pest/mutation, Postgres/Redis no sandbox.

## Bullets úteis

- Manter boilerplate Laravel com compose, prompts de agente e sandbox de mutation.
- Padronizar bootstrap de apps Laravel na própria ferramenta de VM.

## No portfólio / currículo

- Em `PROJECTS` (slug `boilerplate-laravel`).
- Repo: https://github.com/fabriciogferreira/boilerplate-laravel

## Não publicar

`.env` de exemplos com secrets reais, dados de sandbox.
